Реализовать алгоритм PSO (Particle-Swarm Optimization):
-- пусть есть задача J(x)\to\min , x\in \R^n, при наличии системы ограничений g_i(x) \leq 0, i =1..m_1 и g_j(x) = 0, j= 1..m_2
-- вводим параметр "численность популяции частиц" N_p
-- порождаем набор частиц, каждая частица x_k представляет собой вектор x\in\R^n
-- в каждый момент времени каждая частица обновляет своё состояние:

x_k^{l+1}=x_k^l+v_k
v_k^{l+1}=\alpha_1 * v_k^{l}+\alpha_2*U[0,1]*(x_k^{best}-x_k^{l})+\alpha_3*U[0,1]*(x^best-x_k^{l}), где:

x_l^l, v_k^l -- координата и скорость частицы k на текущей итерации

alpha_{1,2,3}>=0, \sum_{i=1...3}\alpha_i=1 -- коэффциенты инерционной, когнитивной и социалькой компонент
U[0,1]-- равномерное распределенная на [0,1] случ.величина
x_k^{best} -- точка из "памяти" x_k с наилучшим значением J, 
x^best -- наилучшее с т.з. J положение частиц из популяции

"время" = переход между итерациями
Если при итерации частица нарушит систему ограничений, нужно организовать "отражение" от ограничений:
-- либо оставляем частицу на старой позиции:
-- либо меняем направление вектора скорости на противоположное и перемещаем частицу в этом направлении:

ОСТАНОВ:
-- по числу итераций
-- по изменению значения критерия
-- по изменению позиций частиц

ЧТО ЗАДАЁМ:

- параметры \alpha_{1,2,3}
- численность популяции
- погрешности для ОСТАНОВ, число итераций


ЧТО ВИЗУАЛИЗИРУЕМ:

- линии уровня функционала
- линии уровня ограничений
- изменение позиций частиц между итерациями

Графики:

1. J(x^best) [l] -- по оси абсцисс номер итерации, по оси ординат наилучшее найденное значение J
2. Поверхность: по осям x,y -- номер итерации и номер частицы, по оси z -- значение J в локации данной частицы на данной итерации
3. На 3D смотрим, как частицы распределяются по фазовому пространству и "стягиваются" в точки экстремума
